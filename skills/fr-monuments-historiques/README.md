# fr-monuments-historiques

Vérifier si un bâtiment est classé ou inscrit au titre des Monuments historiques, ou situé dans un périmètre protégé (abords, SPR). France uniquement.

Adaptation française de `nyc-landmarks`. Sources : voir le SKILL.md. Limites : Résultat limité aux bases consultées ; les périmètres locaux doivent être vérifiés dans le PLU ou le GPU.
