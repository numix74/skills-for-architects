# fr-infractions-urbanisme

Vérifier les infractions et procédures d'urbanisme (procès-verbaux, mises en demeure, arrêtés) concernant un bâtiment. Aucune base nationale ouverte : la donnée s'obtient souvent en mairie.

Adaptation française de `nyc-dob-violations`. Sources : voir le SKILL.md. Limites : Données non publiques dans la plupart des communes ; statut « non disponible » par défaut.
