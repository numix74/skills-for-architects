# fr-dvf-transactions

Rechercher les transactions immobilières DVF (ventes, prix, surfaces) autour d'une parcelle ou dans une commune française. Pour l'historique des ventes uniquement, pas les permis ni les infractions.

Adaptation française de `nyc-acris`. Sources : voir le SKILL.md. Limites : DVF : données personnelles encadrées (article R112 A-3 du Livre des procédures fiscales) ; réutilisation sans indexation par les moteurs de recherche.
