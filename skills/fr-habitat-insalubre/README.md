# fr-habitat-insalubre

Vérifier les arrêtés d'insalubrité, de péril et les signalements d'habitat indigne concernant un logement. Pour l'urbanisme, utiliser fr-infractions-urbanisme.

Adaptation française de `nyc-hpd`. Sources : voir le SKILL.md. Limites : Sources non vérifiées par recherche : à confirmer auprès de l'ARS et de la commune.
