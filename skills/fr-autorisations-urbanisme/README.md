# fr-autorisations-urbanisme

Rechercher les permis de construire, déclarations préalables, permis d'aménager et permis de démolir (base Sitadel) pour une commune ou une parcelle. Pour les infractions, utiliser fr-infractions-urbanisme.

Adaptation française de `nyc-dob-permits`. Sources : voir le SKILL.md. Limites : Sitadel : données de statistiques publiques ; granularité variable selon le fichier.
